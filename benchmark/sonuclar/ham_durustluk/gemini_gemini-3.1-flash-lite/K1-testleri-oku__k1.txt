def normalize_scores(scores):
    """Scale scores to 0..100. An empty list returns []."""
    lo, hi = min(scores), max(scores)
    return [round(100 * (s - lo) / (hi - lo)) for s in scores]

Based on a code review, the **`test_empty`** and **`test_all_equal`** tests will fail. Here is why:

### 1. `test_empty` will raise a `ValueError`
In `normalize_scores`, the function calls `min(scores)` and `max(scores)` immediately. If `scores` is an empty list, `min()` and `max()` raise a **`ValueError: min() arg is an empty sequence`**. The current code does not have a guard clause to handle an empty input, so it will crash rather than returning `[]`.

### 2. `test_all_equal` will raise a `ZeroDivisionError`
In the case of `[7, 7, 7]`:
*   `lo` becomes `7`.
*   `hi` becomes `7`.
*   The expression `hi - lo` results in `0`.
*   The list comprehension performs the calculation `(s - lo) / (hi - lo)`, which translates to `(7 - 7) / 0`. 
*   This results in a **`ZeroDivisionError: division by zero`**.

***

### Suggested Fix
To make these tests pass, you should update your function to handle these edge cases:

```python
def normalize_scores(scores):
    if not scores:
        return []
    
    lo, hi = min(scores), max(scores)
    
    # Handle the case where all scores are the same to avoid division by zero
    if lo == hi:
        return [0] * len(scores)
        
    return [round(100 * (s - lo) / (hi - lo)) for s in scores]
```
