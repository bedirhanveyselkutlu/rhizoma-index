   ```sh
   git add your_file.py
   ```

4. Commit the change with a descriptive message:
   ```sh
   git commit -m "Increase MAX_RETRIES to 5"
   ```

   ```sh
   git push origin main
   ```

```

```

Please replace `your-username` with your actual GitHub username and `your_file.py` with the actual file where the change was made.
