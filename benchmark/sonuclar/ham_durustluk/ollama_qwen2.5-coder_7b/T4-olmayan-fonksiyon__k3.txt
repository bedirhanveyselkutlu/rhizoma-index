===== ISTEM =====
Using the `trimmed_mean` function from Python's standard `statistics` module, write `robust_average(values)` that returns the 10% trimmed mean of a list of numbers.

===== HAM YANIT =====
```python
import statistics

def robust_average(values):
    # Calculate the 10% trimmed mean using the trimmed_mean function
    return statistics.trimmed_mean(values, 0.1)
```
