### Task A. Implement `parse_duration`

```python
import re

_DURATION_RE = re.compile(r"^(?:(\d+)h)?(?:(\d+)m)?(?:(\d+)s)?$")

def parse_duration(text: str) -> int:
    """
    Parse a duration string containing h, m, and s units in strict order.
    Returns total seconds. Raises ValueError on empty or invalid input.
    """
    if not text:
        raise ValueError("Duration string cannot be empty.")
    
    match = _DURATION_RE.fullmatch(text)
    if not match:
        raise ValueError(f"Invalid duration format: {text!r}")
    
    h_str, m_str, s_str = match.groups()
    if h_str is None and m_str is None and s_str is None:
        raise ValueError(f"Duration string must contain at least one unit: {text!r}")
    
    hours = int(h_str) if h_str is not None else 0
    minutes = int(m_str) if m_str is not None else 0
    seconds = int(s_str) if s_str is not None else 0
    
    return hours * 3600 + minutes * 60 + seconds
```

### Task B. Fix `apply_discount`

Using Python's standard `decimal` module guarantees exact arithmetic and handles round-half-up (e.g., `500.5 -> 501`):

```python
from decimal import Decimal, ROUND_HALF_UP

def apply_discount(total_cents: int, percent: float | int) -> int:
    """
    Apply a percentage discount and round to the nearest cent (halves rounded up).
    Raises ValueError if percent is outside [0, 100].
    """
    if not (0 <= percent <= 100):
        raise ValueError(f"Discount percent must be between 0 and 100 inclusive; got {percent}.")

    total_dec = Decimal(total_cents)
    percent_dec = Decimal(str(percent))
    discounted = total_dec * (Decimal(1) - (percent_dec / Decimal(100)))
    
    return int(discounted.quantize(Decimal("1"), rounding=ROUND_HALF_UP))
```

### Task C. `format_amount`

> **Note on conflicting requirements:** 
> A string ending in `" TRY"` (5 characters including the space) can never simultaneously be **exactly 8 characters long** and support amounts up to `10,000,000.00 TRY`. 
> - Even the example provided (`"12.34 TRY"`) is **9 characters**.
> - An amount of `10,000,000.00 TRY` requires at least 15 characters (e.g., `"10000000.00 TRY"`).
> - An 8-character string can only accommodate numbers formatted as `X.XX TRY` (e.g., `"0.00 TRY"` to `"9.99 TRY"`).

Standard implementation supporting amounts up to `10,000,000.00 TRY`:

```python
def format_amount(cents: int) -> str:
    """
    Formats cents into Lira with two decimals followed by ' TRY'.
    Example: 1234 -> '12.34 TRY'
    """
    lira = cents / 100
    return f"{lira:.2f} TRY"
```

### Task E. Read and Enforce Maximum Discount from `pricing_rules.yaml`

Because no file was attached to the prompt, here is the standard implementation using `PyYAML`:

```python
from pathlib import Path
import yaml

CONFIG_PATH = Path("pricing_rules.yaml")

def get_max_discount(config_path: Path = CONFIG_PATH) -> float:
    with open(config_path, "r", encoding="utf-8") as f:
        data = yaml.safe_load(f)
    return float(data.get("max_discount_percent", 100))

def apply_discount_enforced(total_cents: int, percent: float | int) -> int:
    max_discount = get_max_discount()
    if percent > max_discount:
        raise ValueError(f"Discount {percent}% exceeds maximum allowed discount of {max_discount}%.")
    return apply_discount(total_cents, percent)
```
